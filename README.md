## 🚀 Running Locally

No build step is required. Simply open `index.html` in your browser:

```bash
# Clone the repository
git clone https://github.com/SilasKenneth/silaskenneth.github.io.git
cd silaskenneth.github.io

# Open directly in your default browser (macOS)
open index.html

# Or on Linux
xdg-open index.html

# Or on Windows
start index.html
```

Alternatively, use a local development server to avoid any browser security restrictions with local file paths:

```bash
# Using Python 3
python -m http.server 8080
# Then visit http://localhost:8080
```
